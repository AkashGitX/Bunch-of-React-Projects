## 📖 About

**Bunch of React Projects** is an ongoing, hands-on collection of applications built to explore and implement real-world frontend engineering concepts. Each project focuses on a specific area of the React ecosystem, from core fundamentals such as components, hooks and state, to advanced topics such as authentication, backend integration, file storage and production-grade component design.

> 🚀 Projects are added and refined **one by one** as development progresses.

## ⚡ Getting Started

**Prerequisites**

- [Node.js](https://nodejs.org/) `v18` or higher
- `npm` or `yarn`

**Run any project locally**

```bash
# 1. Clone the repository
git clone https://github.com/your-username/bunch-of-react-projects.git

# 2. Navigate into a project folder
cd bunch-of-react-projects/<project-folder>

# 3. Install dependencies
npm install

# 4. Set up environment variables (for backend-based projects)
cp .env.example .env

# 5. Start the development server
npm run dev
```

> 💡 Projects that use **Appwrite** require your own Appwrite project credentials in the `.env` file.
