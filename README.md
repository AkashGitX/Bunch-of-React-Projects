# ⚛️ Bunch of React Projects

An ongoing collection of React projects built to explore and implement real-world frontend concepts, modern React features, reusable components, state management, routing, forms, APIs, authentication, and backend integration.

> 🚀 Projects will be added and updated **one by one** as development progresses.

---

## 🛠️ React Projects

### 01. Background Changer

A simple React application that dynamically changes the background based on user interaction.

### 02. Currency Converter

A React-based currency converter using custom Hooks and API integration to fetch and display currency data.

### 03. Context API Projects

Projects demonstrating global state management and data sharing between React components using Context API.

### 04. React Mega Project

A complete real-world React application combining multiple React concepts into one full-scale project.

### 05. Authentication System

A React authentication system with user registration, login, logout, and session management.

### 06. Appwrite Database Integration

A React application integrated with Appwrite for storing, retrieving, and managing application data.

### 07. File Upload System

A React project implementing file uploads and backend storage using Appwrite.

### 08. Production-Grade React Components

A collection of reusable and scalable React components designed using production-level development practices.

### 09. React Forms

A React form application using React Hook Form for efficient form handling and validation.

### 10. Complete React Application

A full React application combining routing, state management, reusable components, forms, APIs, authentication, and backend services.

### 11. API-Based React Applications

React applications focused on working with APIs using Axios, custom React Query concepts, and proper handling of asynchronous operations and race conditions.
